What it does

Voidwise finds where ducts, pipes and cable trays cross the walls or floors of a linked architectural / structural model, plans one opening for each crossing, lets you review every opening in 3D, and places the approved ones with the add-in's opening families. Works with Revit 2024.

Where to find it

Two places in Revit: the Voidwise tab (Wall Openings, Slab Openings, Update Openings, Export Openings, Import Openings) and the Voidwise panel on the Add-Ins tab (same commands in one menu). Press F1 on a button to open this page.

Quick start - Wall Openings / Slab Openings

  1. Connect the model. Pick the loaded Revit link that holds the walls (or floors).
  2. Options. Choose what to check (ducts, pipes, cable trays), the clearances, and the processing scope: the whole model, the active view, or Selection (the window hides so you can pick elements in Revit, then returns with the picked counts).
  3. Review. Each planned opening is shown in 3D. Approve, reject, or flag it as Needs Review. Neighbouring elements crossing the same wall can share one rectangular opening.
  4. Create. Only approved openings (and, if you tick it, Pending ones) are placed. Rejected and Needs Review openings are never created. A progress bar shows the work, and you can cancel at any time.

Numbers, sizes and parameters

  • Fixed numbers. Every opening gets a number such as OP-W-014 (wall) or OP-S-014 (slab), written to its Mark and to the shared parameter VW_Number. New runs continue after the highest number in the model. Numbers are included in the exported CSV and .voidwise file.
  • Parameters for schedules and filters. Voidwise adds shared parameters in the group "Voidwise": VW_Number, VW_System, VW_Level, VW_SourceId, VW_Status (New / Updated) and VW_Discipline.
  • Sizes. The minimum opening is 50 mm. Rectangles are rounded up to 25 mm or 50 mm, and round openings use standard sleeve diameters (50, 65, 80, 100, 125, 150, 200 mm and so on). All of this can be switched in Options.
  • Sloped pipes through a floor (for example drains) get a rectangular opening that covers their long footprint instead of a round sleeve.
  • Curtain walls and stacked walls are skipped and listed in the result.

When the model changes - Update Openings

After elements move or change size, click Update Openings and press Analyze. Voidwise shows what changed before touching anything:

  • an element that moved or changed size: its opening is moved or resized;
  • elements that now sit next to each other: their separate openings are replaced by one shared opening, and the reverse when an element moves away from a shared opening (replacement openings get new numbers);
  • an opening that no element crosses any more: it is deleted, so it is not sent to the architect for nothing.

Cancelling rolls everything back. Review the message before you confirm.

Sending openings to the architect or structural engineer

Export Openings writes a .voidwise file (shared coordinates, position, size, orientation, family) and a CSV list. The other discipline opens their model and runs Import Openings: Voidwise finds the wall or floor at each opening, places the family and cuts the host. Importing the same file again updates changed openings. Importing is free for everyone.

Plans and trial

Settings

Settings page: dark / light theme, window size (90 / 100 / 110 %), language (English, Arabic, German), save your option defaults or restore factory defaults.

Good practice

  • You remain responsible for checking every opening against your project requirements before issuing drawings or models.
  • Work in a saved model and review the Summary page after creating.
  • If a family cannot be loaded or a wall is not found, the Result card lists the problems.
